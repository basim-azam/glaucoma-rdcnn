# Project status — private

This repository is currently kept **private** while the accompanying paper is under submission. It will be made public alongside the official release of the model checkpoints and the eventual conference acceptance.

While private:

- Model checkpoints and preprocessed dataset archives sit on a OneDrive folder that is share-linked to collaborators by email.
- The codebase, documentation, and the manuscript live in this repository.

At public release the LICENSE file and CITATION entry will be reinstated; placeholders are kept as `_LICENSE_pending.txt` and `_CITATION_pending.cff`.
